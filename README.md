# AnimeT Website

## Project Description
AnimeT is a simple, responsive HTML website built with Tailwind CSS that showcases some of my favorite anime characters and anime series. 

## Setup and Viewing Instructions
To view the website locally, simply:
1. Download or clone the repository.
2. Open the `home.html` or `anime.html` file directly in browser 

## Features
- **Responsive Design:** Uses Tailwind CSS to provide a mobile-friendly layout.
- **Accessible Navigation:** Mobile toggle navigation menu for better usability on mobile devices.
- **Image Descriptions:** Alt attributes on images to support screen readers.
